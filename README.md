# React + Spring Boot

A full-stack web application built with React and Java Spring Boot, demonstrating frontend development, backend API integration, and database connectivity.

## Tech Stack

- **Frontend:** React
- **Backend:** Java, Spring Boot
- **API:** REST API
- **Tools:** Git, GitHub, npm, Maven

## Project Structure

```text
React-SpringBoot/
├── frontend/
├── backend/
└── README.md
```

## Getting Started

Clone the repository:

```bash
git clone https://github.com/zrzndn/React-SpringBoot.git
cd React-SpringBoot
```

Start the backend and frontend separately using their respective configurations.

## Goals

- Build a full-stack application.
- Practise REST API integration.
- Improve frontend and backend development skills.
- Explore testing and deployment.
